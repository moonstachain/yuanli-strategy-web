# 原力战略 · Web

> **把你的不可复制，变成会复利的事业系统。**

`yuanli-strategy-web` 是原力战略三部曲的公开文章网站与用户行动入口。

它负责：

- 面向企业家、专家型创业者与高认知个体，解释 AI 时代的事业变化；
- 将原力战略正典翻译为可阅读、可诊断、可行动的内容；
- 连接文章、概念、案例、工具与学习路径；
- 收集公开安全的行动反馈，并向 Soul 提交回写候选。

它不负责：

- 修改原力战略最高正典；
- 保存创始人或客户私密资料；
- 以页面存在代替真实 Outcome；
- 复制 Soul、Brain、PMO 或 Runtime 的真账。

## 法权边界

- 方法论正典与治理真源：[`moonstachain/yuanli-strategy-soul`](https://github.com/moonstachain/yuanli-strategy-soul)
- 本仓定位：公开安全投影、文章内容、阅读体验与行动入口

总原则：

> **Soul 定义“什么是对的”，Web 负责“如何让人看懂、用起并留下行动证据”。**
