### 导出的验证边界

云端浏览器没有在限定等待内返回文件下载事件，因此不将文件已落到下载目录列为已验证结果。已直接观察到真实 Blob 下载链接、完整导出文本，并验证「选中文本，手动复制」能够把全部内容带走。界面只提示「导出内容已准备好」，不把准备完成写成下载成功。

## 发布门槛及仍需真实验证的事项

发布工作流必须先成功完成官方 `build-site.mjs` 构建，再提交、推送并打包同一源码；最终版本、提交与部署 ID 记录在 PR #45。平台返回 `succeeded` 才计为发布成功。本地浏览器验收不能替代平台部署证据。

以下事项没有被本轮工程验收替代：

1. 真实负责人使用自己的账号完成一次联系请求处理。受保护 API 已测试，但本轮没有冒用真人身份进行浏览器登录或处理真实请求。
2. 五位真实目标访客完成理解、阅读、练习与合作选择的观察；没有据此声称转化率提升。
3. 确定联系资料保存期限和真人处理节奏。当前没有自动到期清理，也不承诺未经确认的回复时效；复看日期不是自动通知。
4. 真实人物影像、可公开客户案例、课程成熟度与外部渠道运营状态继续以授权和真实证据为准。

问题卡保存在用户主动选择的当前浏览器中，只有一份；联系请求保存在受保护的运行时中。负责人列表目前显示最近 100 条。后续规模增长、跨设备同步和自动通知不属于本轮已交付能力。
