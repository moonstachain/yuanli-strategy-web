# 原力战略Web · 90天路线 v2.1

- 状态：`execution-ready`
- 周期：2026-08-05—2026-11-03
- 北极星：每月形成一条“认知 → 行动 → Outcome → Changed Rule → 第二任务复用”的公开安全证据链
- 当前最高优先级：先证明陌生用户能够完成第一次成功，再扩大内容节奏

## 1. 核心裁决

90天不以文章数量、栏目数量或页面数量为最高验收。

```text
媒体获得注意
→ 症状入口产生共鸣
→ 3分钟原力导航形成优先验证假设
→ 唯一推荐工具产生行动
→ 7天/30天观察Outcome
→ Changed Rule候选
→ 第二任务事前加载
```

## 2. WIP限制

- 认知行动包 ≤ 2

- 真人诊断/导航测试版本 ≤ 1

- 技术基础设施大项 ≤ 1
- 新一级栏目 = 0

## 4. D15—D30｜5—8位首次用户测试

按照 `FIRST-SUCCESS-JOURNEY-v1.md` 执行：

1. 30秒理解测试；
2. 90秒入口选择；
3. 3—10分钟导航/工具完成；
4. 关闭后重新进入，测试继续上次进度。

最低样本：5位；建议样本：8位。

收集：

- 用户原话；
- 错误入口；
- 犹豫点；
- 放弃点；
- 不可信表达；
- 推荐行动是否匹配；
- 移动端阻断。

每轮最多修改3个导航题目或结果规则，防止同时改变全部变量。

## 5. D31—D45｜真实行动

目标：至少10名目标用户完成导航或推荐工具。

必须产生：

- 匿名必要Action Receipt；
- 用户自行确认的优先验证位置；
- 一个现实实验；
- 7天回访时间；
- 失败、反例和误判记录。

不得把以下指标当Outcome：

- 页面访问；
- 点击；
- 表单生成；
- 用户说“有启发”；
- 点赞和转发。

## 6. D46—D60｜内容与商业物种节奏

在首次成功路径无阻断后，恢复稳定内容节奏：

```text
每周：1个原力前哨包
双周：1个诊断室/导航复盘
每月：1个商业物种事实包
每月：1个OS实验复盘
```

首个商业物种优先从丰田、宜家、Costco中选择一个，必须有人工作品、原始来源、反例和边界。

《300年康波》《原力群星志》《原力反例志》保持参考与候选位，不并行争夺深度事实包WIP。

## 7. D61—D75｜Outcome与Changed Rule

至少完成：

- 3—5名用户7天回访；
- 1—3名用户30天回访；
- 一条内容、导航或工具规则被真实证据改变；
- Changed Rule候选包含旧规则、证据、局限、反例和影响范围；
- 未经Soul Human Gate不晋级正典。

## 8. D76—D90｜第二任务复用

选择明确Task2：

- 下一场媒体战役；或
- 第二版导航；或
- 第二个商业物种；或
- 第二次真人诊断。

Task2开始前必须显式加载Changed Rule，并记录：

```text
loaded_rule
loaded_at
changed_decision
changed_action
observed_difference
limitations
```

只有规则实际改变第二次行动，才可标记Compounding。
