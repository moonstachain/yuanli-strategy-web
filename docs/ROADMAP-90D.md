# 原力战略 Web · 90 天落地路线图

- 项目：`moonstachain/yuanli-strategy-web`
- 起始日：2026-08-05
- D90：2026-11-03
- 北极星：让原力战略从“可阅读的思想”升级为“可诊断、可行动、可留证、可回写的公开战略界面”。

## 总验收

D90 时至少满足：

1. 网站可稳定访问，移动端与桌面端核心页面无阻断；
2. 六大前台主题、三部十二模块与五类文章形成稳定导航；
3. 发布不少于 24 篇通过内容协议的文章；
4. 上线不少于 3 个最小行动工具；
5. 至少 3 个公开安全案例拥有 Baseline → Action → Outcome → Changed Rule 证据链；
6. 至少 1 条文章或工具产生的规则，在下一次真实内容/工具任务中被读取复用；
7. Web 的回写候选经过 Soul 的 Human Gate，不越权修改正典。

---

## Phase 1 · 协议冻结（D0—D14，2026-08-05—2026-08-19）

### 目标

先冻结“网站为什么存在、内容如何进入、如何验收”，再增加页面数量。

### 交付

- [x] 新仓与法权边界初始化；
- [x] Astro + MDX 工程基线；
- [x] 六大前台主题；
- [x] 三部十二模块映射；
- [x] Article Front Matter Schema；
- [x] 首页、主题页、文章列表页、文章详情页；
- [x] 三篇总纲种子文章；
- [x] GitHub Actions build / Pages 工作流；
- [ ] 24 篇首发文章逐篇确定 Owner、证据等级与发布时间；
- [ ] 三个行动工具冻结字段和验收；
- [ ] Soul 建立 Web 跨仓入口与回写接口。

### Exit Gate

- `npm install --no-audit --no-fund && npm run build` 通过；
- 所有已发布文章通过 Schema；
- 导航不存在 404；
- 每篇文章拥有模块、主题、贵任务、证据等级、正典状态与下一步行动；
- 本仓不存私密资料，不宣称未验证 Outcome。

## Phase 2 · MVP 上线（D15—D45，2026-08-20—2026-09-19）

### 目标

让一个陌生用户能够完成“进入 → 理解 → 诊断 → 行动”。

### 交付

- [ ] 首批 24 篇文章达到 published；
- [ ] 5 分钟原力战略体检 v0.1；
- [ ] AI 清算卡、三链诊断卡、项目回写卡；
- [ ] 文章上游/下游/工具关联；
- [ ] 站内搜索；
- [ ] SEO、OpenGraph、sitemap、RSS；
- [ ] 3 个案例的公开安全页；
- [ ] 公众号/网站内容发布链；
- [ ] 基础匿名分析，只收集必要事件。

### Exit Gate

- 新用户 5 分钟内能够找到自己的三部曲位置；
- 至少 10 名目标用户完成一次工具动作；
- 至少 3 条用户反馈改变文章、工具或导航；
- 未经 Human Gate 的派生判断不标为 canon。

---

## Phase 3 · 内容复利（D46—D90，2026-09-20—2026-11-03）

### 目标

证明 Web 不只是内容发布器，而是能够产生学习与回写的系统。

### 交付

- [ ] 用户收藏与学习路径；
- [ ] 文章—概念—模块—案例—工具关系图；
- [ ] AI 问答入口仅引用公开安全内容；
- [ ] 行动回执与 Outcome 回访；
- [ ] 案例证据等级与反例区；
- [ ] 每周“原力观察”、每月正典专题节奏；
- [ ] Web → Soul 的 Evolution Note 候选包；
- [ ] 第二轮内容根据真实使用数据重构。

### Exit Gate

- 至少一条 Changed Rule 在 Task2 被明确加载；
- 至少三篇文章因用户行动证据发生版本升级；
- 至少一个案例达到 Validated；
- 若没有真实 Outcome，状态必须保持 NOT_RUN / Done，不得包装为成功。

---

## WIP 限制

任一时点同时进行：

- 文章不超过 6 篇；
- 工具不超过 2 个；
- 案例不超过 2 个；
- 技术基础设施大项不超过 1 个。

任何新需求必须先回答：它服务哪个用户症状、哪个 A1—C4 模块、留下什么可复用资产、挤掉哪个现有 WIP。
