# 原力战略 Web · 90天运行路线图 v2.0

- 项目：`moonstachain/yuanli-strategy-web`
- 起始日：2026-08-05
- D90：2026-11-03
- 北极星：每月形成一条“认知 → 行动 → Outcome → Changed Rule → 第二任务复用”的公开安全证据链。
- 当前执行分支：`feat/media-action-engine-v1`

## 1. 战略重构

网站从“方法论门户”升级为：

> **AI时代专家型创业者的前沿战略媒体与事业进化实验场。**

前台内容链：

```text
Signal
→ Evidence
→ Judgment
→ Action
→ Outcome
→ Learning
→ 第二次任务复用
```

后台治理链：

```text
Soul CTX
→ Brain EVD
→ Content Engine DEC/WPK
→ Web ACT
→ Brain/Content Engine OUT/LRN
→ Soul Human Gate
```

## 2. 90天总验收

D90至少满足：

1. 网站桌面端与移动端核心页面无阻断；
2. 首页第一注意力来自时代问题、封面故事和行动，而非治理矩阵；
3. 原力前哨形成至少8个稳定认知行动包；
4. 原力商业物种志完成2—3个经过事实门和人工裁决的深度案例；
5. 至少3个授权、脱敏的真人诊断试点；
6. 至少30名目标用户完成一张行动卡；
7. 至少6名用户完成7天或30天Outcome回访；
8. 至少1个公开案例达到Validated；
9. 至少1条Changed Rule在第二次真实内容、工具或诊断任务中被事前加载；
10. Web回写候选经过Soul Human Gate，不越权修改正典；
11. 3—5名目标用户完成导航与内容入口可用性测试；
12. 未有真实证据的任务保持NOT_RUN，不包装为成功。

## 3. 固定运行节奏

```text
每周：1个原力前哨包
双周：1个原力诊断室
每月：1个原力商业物种事实包或深度案例
每月：1个原力OS实验复盘
```

一个认知行动包最多包含：

- 1篇Hook；
- 1篇Evidence或事实包；
- 1篇Mechanism；
- 1篇Action；
- 1份Reflection / Changed Rule候选。

### Exit Gate

只有同时具备以下证据，才允许宣称Compounding：

```text
Task1真实行动
＋ Outcome人类判定
＋ Changed Rule获批
＋ Task2事前加载回执
＋ Task2判断或行动发生可观察变化
```

## 4. WIP限制

任一时点同时进行：

- 认知行动包不超过2个；
- 长文不超过4篇；
- 工具不超过1个；
- 真人诊断不超过1个；
- 商业物种或其他深度事实包总数不超过1个；
- OS实验不超过1个；
- 技术基础设施大项不超过1个。

新热点必须明确：

1. 服务哪个真实用户症状；
2. 属于哪个战役角色；
3. 绑定哪个A1—C4模块；
4. 留下什么行动或资产；
5. 挤掉哪个现有WIP。
