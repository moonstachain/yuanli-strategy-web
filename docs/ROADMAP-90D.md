# 原力战略 Web · 90 天落地路线图

- 项目：`moonstachain/yuanli-strategy-web`
- 起始日：2026-08-05
- D90：2026-11-03
- 北极星：让原力战略从“可阅读的思想”升级为“可诊断、可行动、可留证、可回写的公开战略界面”。

## 内容架构

- 正典基础层：[`EDITORIAL-BACKLOG.md`](EDITORIAL-BACKLOG.md)
- 媒体战役层：[`EDITORIAL-CAMPAIGNS-12W-v2.md`](EDITORIAL-CAMPAIGNS-12W-v2.md)
- 时代旗舰系列：[`EDITORIAL-SERIES-300Y-KONDRATIEV-v1.md`](EDITORIAL-SERIES-300Y-KONDRATIEV-v1.md)
- 人物旗舰系列：[`EDITORIAL-SERIES-FORCE-CONSTELLATIONS-v2.md`](EDITORIAL-SERIES-FORCE-CONSTELLATIONS-v2.md)

```text
正典基础层保证概念完整、边界稳定与长期可引用。
媒体战役层从时代事件进入，建立连续叙事、用户行动与结果回写。
旗舰系列层建设高纵深、可跨周期复用的主题资产，但必须通过更严格的事实审阅门。
```

两套旗舰系列构成双螺旋：

```text
《300年康波》回答：时代为什么在那个时刻换轨？
《世界差一点走向另一条路》回答：为什么偏偏是这个人，在结果未知时作出了不同选择？
原力工具回答：这要求今天的用户完成什么判断和行动？
```

两套系列当前均为 `planning baseline`，不自动替换正在执行的12周媒体战役，也不自动占用现有24个编辑槽位。任何正式排期都必须说明挤掉哪个WIP，并先完成事实包、争议与反例、类比边界和行动出口。

## 总验收

D90 时至少满足：

1. 网站可稳定访问，移动端与桌面端核心页面无阻断；
2. 六大前台主题、三部十二模块与五类文章形成稳定导航；
3. 正典基础层24项均有明确状态、Owner、证据包与复用出口；
4. 12周媒体战役的24个编辑槽位均有 `published / rescheduled / rejected` 状态，且门户已发布不少于24篇通过内容协议的文章；
5. 上线不少于3个最小行动工具；
6. 至少3个公开安全案例拥有 Baseline → Action → Outcome → Changed Rule 证据链；
7. 至少1条文章或工具产生的规则，在下一次真实内容/工具任务中被读取复用；
8. Web的回写候选经过Soul的Human Gate，不越权修改正典；
9. 《300年康波》至少完成1771首篇试点的事实包与编辑裁决；未通过事实门不得计入发布任务；
10. 《世界差一点走向另一条路》至少完成凯尔西首篇的事实包、Human Gate工具草案与编辑裁决；未通过事实门不得计入发布任务。

## WIP限制

任一时点同时进行：

- 长文不超过4篇；
- 工具不超过1个；
- 案例不超过2个；
- 技术基础设施大项不超过1个；
- 历史事实包总数不超过1个；
- 人物旗舰长文不超过1篇。

《300年康波》与《世界差一点走向另一条路》共用“历史事实包≤1”的WIP预算，不允许同时启动两个未经审阅的历史研究包。

任何新热点或旗舰栏目文章若要替换当周Hook，必须先回答：它服务哪个用户症状、哪个A1—C4模块、留下什么可复用资产、挤掉哪个现有WIP。
