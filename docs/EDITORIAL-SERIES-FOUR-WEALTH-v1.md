# 原力创业·四种财富｜编辑协议 v1

- 状态：`execution-ready`
- 层级：文明传播层 / 财富解释层
- 后台正典：`B1 原力借势 → B2 品类独创 → B3 模式升维 → B4 壁垒锁定`
- 母公理：做会自我繁殖的事，不做一次性的事

## 1. 专题母问题

> 真正的财富究竟储存在哪里？

本专题用“时代、心智、空间、时间”解释原力创业四步如何把原力母体生成的独特价值，逐层加工为可放大、可定价、可复制、可长期保留的事业财富。

## 2. 三层语言不得混用

| 层级 | 表达 | 用途 |
|---|---|---|
| 后台正典 | 原力借势、品类独创、模式升维、壁垒锁定 | 定义、治理、模块接口 |
| 文明机制 | 时、名、器、权 | 跨学科解释 |
| 财富解释 | 时代、心智、空间、时间的财富 | 面向用户传播与案例拆解 |

“四种财富”不修改三部十二模块，不新增第五种壁垒。母体是生成源，飞轮是四种控制权相互强化的结果。

## 3. 核心链路

```text
生命的财富：原力母体
→ 时代的财富：获得历史杠杆
→ 心智的财富：获得理解与定价
→ 空间的财富：形成跨节点价值网络
→ 时间的财富：沉淀长期控制权
→ 真实Outcome与回写
→ 生命财富升级
```

## 4. 认知行动包

```text
Hook：真正的财富储存在哪里？
→ Mechanism：四种财富总纲
→ Evidence：任天堂、爱马仕、Costco、LEGO
→ Reflection：柯达断链反例
→ Action：四种财富诊断卡
```

## 5. 案例选择门

每个案例必须同时具备：

1. 一个可见的命运现场；
2. 至少两种在当时都合理的选择；
3. 可追溯的事实来源；
4. 文：人与意义层的解释；
5. 武：产品、组织、链路与财务结构；
6. 明确的原力模块坐标；
7. 至少一个反例、边界或未完成处；
8. 一个能够迁移到专家型创业者的行动问题。

## 6. 五个首批样本

| 样本 | 主财富 | 核心命题 | 主要模块 |
|---|---|---|---|
| 任天堂 Wii | 时代财富 | 不在旧参数上更强，而是扩大“谁算用户” | B1 |
| 爱马仕 | 心智财富 | 解释权必须由真实交付托底 | B2 / B4 |
| Costco | 空间财富 | 留存不是制造离开痛苦，而是让留下持续值得 | B3 / B4 |
| LEGO | 时间财富 | 过去的资产仍可参与创造未来 | B4 / C4 |
| 柯达 | 断链反例 | 既有时间财富可能反过来阻止新表型 | A2 / B1 / C3 |

## 7. 发布门

- 标题承诺与正文一致；
- 事实、推论与原力解释明确分层；
- 外部事实进入来源账；
- B4只使用虚、实、入、出四种控制权；
- 至少一个反例或限制；
- 有唯一下一步；
- 有Outcome Question；
- 页面存在不等于用户理解或经营Outcome。

## 8. 专题验收

### Done

- 总纲、四个正例、一个反例和行动卡可访问；
- 专题页能够自动聚合；
- 栏目入口与文章内链可用；
- CI构建通过。

### Validated

- 至少5位目标用户能无提示区分四种财富；
- 至少3位用户能把自己的事业放入四种财富链；
- 记录误解、跳跃与错误归因。

### Compounding

- 用户行动产生的案例改变诊断卡或文章规则；
- 下一次案例生产明确加载本专题的编辑协议和来源账。
