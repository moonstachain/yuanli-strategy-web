# 信息架构 v2.0｜媒体前台 × 正典后台

- 状态：`accepted / execution-baseline`
- 日期：2026-08-06
- 核心裁决：前台从变化、冲突、人物、企业和用户症状进入；后台用栏目、主题、A1—C4、证据和回写保证不说散。

## 1. 第一性目标

网站不是把Soul搬到网页，也不是让陌生用户先学习完整体系。

用户路径必须是：

```text
看见一个与自己有关的变化
→ 理解原力战略的独特解释
→ 完成一个最小行动
→ 留下可观察结果
→ 结果进入下一轮内容与规则候选
```

前台母承诺：

> **AI正在重写每一种职业。原力战略帮助你把不可复制，变成会复利的事业。**

## 2. 前后台双层结构

### 2.1 前台：用户看见什么

```text
原力前哨
商业物种
诊断室
OS实验室
工具
正典
```

前台以媒体和行动语言表达，不要求用户先理解A1—C4。

### 2.2 后台：系统如何治理

```text
六大用户主题
七个常设栏目
阶段性媒体战役
四个旗舰系列
五种文章类型
三部十二模块
证据等级
正典状态
Outcome与回写状态
```

后台治理不消失，但不占据首页第一注意力。

## 3. 当前四个重点内容引擎

### 原力前哨

母问题：什么正在贬值，什么正在升值？

最小单元：

```text
Signal
→ Evidence status
→ Judgment
→ Action
→ Outcome Question
```

### 原力商业物种志

母问题：一家公司如何通过关键选择成为不同于同行的新物种？

研究骨架：

```text
时代窗口
× 创始人母体
× 用户贵问题
× 品类
× 三条链路
× 虚实出入四种控制权
× OS遗传
```

### 原力诊断室

母问题：用户当前真正卡在A1—C4哪一环？

固定链路：

```text
真实症状
→ 表层解释
→ 模块定位
→ 最小行动
→ 7天回执
→ 30天Outcome
→ Changed Rule候选
```

### 原力OS实验室

母问题：一次判断如何进入文脉、大脑、地图、链路并改变第二次行动？

公开对象：任务边界、人机分工、Human Gate、失败、回写和第二次加载，不把工程产物本身包装为业务成功。

## 4. 主导航

正式前台导航：

```text
前哨
商业物种
诊断室
OS实验室
工具
正典
```

“关于”和“透明建设账”从移动菜单、页脚和正文入口进入。

治理裁决：

- 原力书房继续作为常设栏目与文章来源类型，不占一级导航；
- 原力案例库进入商业物种和诊断室，不再单独争夺一级入口；
- “旗舰”不作为抽象导航名，直接展示具体旗舰产品；
- A1—C4用于后台坐标、筛选和深度阅读，不作为冷用户一级入口。

## 5. 首页顺序

```text
时代母问题
→ 本周原力裁决
→ 封面认知行动包
→ 三个用户入口
→ 原力信号
→ 商业物种
→ 阅读到Outcome
→ 行动工具
→ 三部正典后台
→ 最新文章
```

“3部、12模块、7栏目、4旗舰、6主题”和建设状态不再占据首屏。透明建设账移至 `/status/`。

## 6. 页面路由

```text
/
├─ /articles/
│  └─ /articles/[id]/
├─ /columns/
│  └─ /columns/[id]/
├─ /themes/
│  └─ /themes/[id]/
├─ /tools/
│  ├─ /tools/ai-clearance/
│  ├─ /tools/category-hypothesis/
│  └─ /tools/project-backwrite/
├─ /status/
├─ /about/
└─ /404/
```

后续有真实数据后再增加：

```text
/diagnosis/
/cases/
/learning-paths/
/search/
```

在真人内容、证据与隐私边界成熟前，诊断和案例继续使用栏目页，不建立伪动态数据页。

## 7. 文章页固定合同

1. 标题：熟悉对象＋反常识变化＋个人后果；
2. 30秒原力裁决；
3. 发生了什么：事实、日期和来源；
4. 为什么旧解释不够；
5. 原力机制；
6. 对专家型创业者意味着什么；
7. 反例与边界；
8. 一个最小行动；
9. Outcome Question。

文章元数据允许增加：

- `campaign`；
- `contentRole`：hook / evidence / mechanism / action / reflection；
- `sourceStatus`；
- `outcomeQuestion`。

这些字段向后兼容，不替换既有 `module / theme / articleType / evidenceLevel / canonStatus / nextAction`。

## 8. 最小内容产品

生产单位从“单篇文章”升级为“原力认知行动包”：

```text
Hook｜获得注意
Evidence｜约束事实边界
Mechanism｜形成原力解释
Action｜推动现实动作
Reflection｜记录Outcome与Changed Rule
```

Evidence不存在时必须保持 `NOT_RUN / needs_sources`，允许先发布明确标注的假设文章，但不得把它改写为verified趋势报告。

## 9. 边界裁决

```text
主题不是栏目。
文章类型不是栏目。
战役不是永久栏目。
旗舰不是高频资讯流。
A1—C4不是面向小白的一级导航。
页面存在不等于栏目稳定运行。
行动发生不等于Outcome成立。
Changed Rule存在不等于Compounding，必须有第二任务事前加载证据。
```
