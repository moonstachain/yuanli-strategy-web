# 原力战略Web · 信息架构 v2.1

- 状态：`execution-ready`
- 核心原则：一级导航回答“我来做什么”，二级导航回答“网站里有什么”
- 首次用户目标：30秒理解价值，90秒找到入口，3—10分钟完成一个动作

## 1. 产品角色

Web是：

- 前沿战略媒体；
- 首次用户成功旅程；
- 公开文章、工具与行动入口；
- public-safe证据与Outcome投影。

Web不是：

- Soul正典真源；
- Brain证据真账；
- Content Engine经营总账；
- PMO项目状态账；
- 客户私密数据仓。

## 2. 一级导航

```text
看时代
找原力
做生意
建系统
工具
探索
搜索
```

### 看时代

进入原力前哨，回答：

> 世界正在发生什么，这会改变怎样的长期选择？

### 找原力

进入3分钟原力导航A路径，回答：

> 我真正不可复制的生成源是什么？

### 做生意

进入3分钟原力导航B路径，回答：

> 为什么用户认可我，却没有形成可放大的选择？

### 建系统

进入3分钟原力导航C路径，回答：

> 为什么团队和AI越来越多，事业仍然离不开我？

### 工具

按用户收益进入行动工具。

### 探索

承载资产型入口：

- 原力正典；
- 商业物种志；
- 原力诊断室；
- 原力OS实验室；
- 全部文章；
- 透明建设账；
- 关于。

### 搜索

进入文章中心搜索，不与业务任务并列为文字栏目。

## 3. 首页信息流

```text
第一屏：一个母叙事＋一个主行动
第二屏：A/B/C三类真实症状
第三屏：本周封面故事
第四屏：原力前哨
第五屏：行动工具
第六屏：三条阅读轨道
第七屏：本月商业物种主展
第八屏：诊断之后的三阶段地图
第九屏：证据与边界
```

### 第一屏

主行动：`开始3分钟原力导航`

次行动降级为文字入口：`第一次来，先看原力战略是什么`

历史状态存在时显示：`继续上次进度`

### 第二屏

只显示：

- 找不到独特性；
- 生意无法放大；
- 事业离不开本人。

不要求用户先理解A1—C4。

### 三阶段地图

```text
找到不可复制 → A1—A4
让市场选择你 → B1—B4
让事业持续进化 → C1—C4
```

完整十二模块进入正典页。

## 4. 3分钟原力导航

URL：`/start/`

入口参数：

```text
/start/?path=A
/start/?path=B
/start/?path=C
```

结果结构：

```text
优先验证坐标
判断依据
为什么先从这里开始
唯一下一步
边界说明
```

状态：`navigation hypothesis`。

## 5. 文章中心

URL：`/articles/`

承担深度用户需求：

- 关键词搜索；
- 文章类型筛选；
- 标题、症状、概念、模块检索；
- 结果计数。

首页不展示完整文章总账和多维筛选器，只展示：

- 第一次来；
- 正在发生；
- 开始行动。

## 6. 工具中心

URL：`/tools/`

每张卡必须回答：

- 适合谁；
- 需要什么；
- 得到什么；
- 接下来做什么。

正典工具名与模块坐标作为副标题，不作为陌生用户的唯一理解入口。

## 7. 本地连续性

不建账户系统，第一阶段使用浏览器本地状态：

```text
yuanli-navigation:v0.1
yuanli-journey:last
yuanli-tool:<pathname>
```

支持：

- 恢复导航进度；
- 恢复工具草稿；
- 首页继续上次行动。

## 8. 证据与治理入口

首页只保留一句信任承诺：

> 所有内容标明证据等级；没有真实结果的内容，不写成成功案例。

详细信息进入：

- `/status/`；
- 文章证据标记；
- 关于页；
- 内容协议。

## 9. 无障碍与移动端

必须覆盖：

- 键盘可达；
- 明确焦点；
- fieldset/legend语义；
- aria-live结果；
- reduced motion；
- 长中文标题；
- 390×844与375×667；
- Sticky导航不遮挡结果与锚点。

## 10. 禁止事项

- 不在首页恢复七栏目组织结构平铺；
- 不在首页恢复文章多维总账；
- 不把3分钟导航称为Validated诊断；
- 不用本地状态冒充用户账户；
- 不让公开Web覆盖Soul、Brain或PMO真源；
- 不以页面上线证明Outcome。
