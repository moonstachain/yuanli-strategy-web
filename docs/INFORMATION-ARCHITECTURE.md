# 信息架构 v1.0

## 1. 五层内容结构

### 第一层｜六大用户主题

用户按当前问题进入：

1. AI与个体未来；
2. 找到不可复制；
3. 创造新品类；
4. 建设好生意；
5. 创始人变系统；
6. 原力案例库。

主题负责筛选、推荐和学习路径，不负责规定更新节奏。

### 第二层｜七个常设栏目

1. 原力观察；
2. 原力正典；
3. 原力诊断室；
4. 原力案例库；
5. 原力工具；
6. 原力OS实验室；
7. 原力书房。

常设栏目负责持续生产什么内容。

### 第三层｜媒体战役

六场两周制战役负责阶段性集中解释一个结构冲突：

```text
Hook
→ Mechanism
→ Proof
→ Action
→ 用户证据
→ 回写候选
```

### 第四层｜四个旗舰系列

1. 原力时代志｜《300年康波》；
2. 原力群星志｜《世界差一点走向另一条路》；
3. 原力商业物种志｜《一家公司如何成为新物种》；
4. 原力反例志｜《那些看起来正确却没有成立的战略》。

旗舰系列负责形成跨周期思想资产，不追求高频。

### 第五层｜后台治理

- 三部：asset / startup / os / cross；
- 十二模块：A1—C4；
- 五种文章类型；
- 证据等级；
- 正典状态；
- 用户症状；
- 贵任务；
- 关联工具；
- Outcome状态。

## 4. 首页阅读路径

```text
母承诺
→ 今天最重要的判断
→ 三部症状诊断
→ 七个常设栏目
→ 四个旗舰系列
→ 六大用户主题
→ 三部十二模块

→ 最小行动
```

---

## 5. 栏目页固定组件

1. 栏目名称与母问题；
2. 栏目承诺；
3. 真实建设状态；
4. 更新节奏；
5. A1—C4坐标；
6. 首批内容候选；
7. 已可阅读内容；
8. 行动与证据边界。

状态只允许：

- `live`；
- `execution-ready`；
- `planning-baseline`。

---

## 6. 文章页固定组件

1. 核心裁决；
2. 现实症状；
3. 旧有解释；
4. 第一性机制；
5. 原力坐标；
6. 案例或反例；
7. 行动卡；
8. 上游、下游与回写入口。

---

## 7. 边界裁决

```text
主题不是栏目
文章类型不是栏目
战役不是永久栏目
旗舰不是高频资讯流
A1—C4不是面向小白的一级导航
```

栏目页面存在只证明门户外显完成，不证明栏目稳定运行、用户完成行动或产生Outcome。
