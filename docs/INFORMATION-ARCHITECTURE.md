# 信息架构 v0.1

## 1. 双层结构

### 前台：用户看得懂

1. AI 与个体未来；
2. 找到不可复制；
3. 创造新品类；
4. 建设好生意；
5. 创始人变系统；
6. 原力案例库。

### 后台：正典与机器可治理

- 三部：asset / startup / os / cross；
- 十二模块：A1—C4；
- 五种内容类型；
- 证据等级、正典状态、贵任务、用户症状和下一步行动。

## 3. 首页阅读路径

```text
母承诺
→ 今天最重要的判断
→ 三部症状诊断
→ 六大主题
→ 三部十二模块
→ 首发文章
→ 最小行动
```

## 4. 文章页固定组件

1. 核心裁决；
2. 现实症状；
3. 旧有解释；
4. 第一性机制；
5. 原力坐标；
6. 案例或反例；
7. 行动卡；
8. 上游、下游与回写入口。
