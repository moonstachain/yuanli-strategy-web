# 门户首次用户成功旅程 v1

- 状态：`execution-ready / evidence NOT_RUN`
- 适用仓：`moonstachain/yuanli-strategy-web`
- 上位边界：Soul 管法；Web 只做公开安全投影、用户行动入口和必要本地状态
- 北极星：陌生专家型创业者在首次访问中完成一项有价值的行动，并知道下一步

## 1. 核心裁决

门户不再把“展示完整体系”作为首次访问目标，而把首次成功冻结为：

```text
看见我
→ 理解我
→ 定位我
→ 帮我完成一次
→ 记住我做到哪里
```

它与媒体和SOUL闭环的关系：

```text
前沿信号吸引注意
→ 真实症状产生共鸣
→ 3分钟原力导航形成优先验证假设
→ 推荐唯一下一步
→ 工具形成可见资产
→ 现实行动与Outcome
→ Changed Rule候选
→ 第二任务复用
```

## 3. 首页P0合同

首页首次访问必须满足：

1. 首屏只有一个主行动：`开始3分钟原力导航`；
2. 次行动降级为解释入口，不与主行动视觉同级；
3. 第二屏只展示A/B/C三类现实症状；
4. 用户问题在前，正典坐标在后；
5. 三部十二模块只以三个阶段出现，完整地图进入正典页；
6. 工具卡先说适合谁、需要什么、得到什么、接下来做什么；
7. 文章搜索与筛选只存在于文章中心；
8. 建设状态与证据纪律后移，但必须可达；
9. 本地存在历史状态时，显示“继续上次进度”。

## 4. 3分钟原力导航 v0.1

### 定位

`navigation hypothesis`，不是人格测评、能力评级或经验证诊断。

### 输入

9个现实症状，每题三级选择：

- 基本不符合；
- 有一些；
- 非常符合。

### 输出

- 一个优先验证坐标；
- 一段判断依据；
- 一个唯一下一步；
- 一个明确边界说明。

### 当前坐标

- A1：发现母体
- A2：回到母体
- A3/A4：获得与显化原力
- B1：原力借势
- B2：品类独创
- B3：模式升维
- B4：壁垒锁定
- C1/C2：文脉与大脑
- C4：一条链路

### 数据边界

- 答案与结果默认只保存在浏览器 `localStorage`；
- 不自动上传；
- 不填写客户姓名、密钥或未经授权真账；
- 公开测试只收集匿名必要指标；
- 若未来接入服务端，必须另立隐私、授权与删除合同。

## 5. 本地连续性合同

键：

```text
yuanli-navigation:v0.1
yuanli-journey:last
yuanli-tool:<pathname>
```

首页可恢复：

- 未完成导航；
- 最近导航坐标；
- 推荐行动；
- 最近工具；
- 工具完成进度。

本地状态不等于用户身份，不得在未授权情况下跨设备或跨浏览器合并。

## 6. 首次用户测试

样本：5—8位目标用户，优先专家型创业者、传统产业早期创业者、独立专家。

### 任务一｜30秒理解

用户只看首页首屏，回答：

- 这个网站是做什么的？
- 与你有什么关系？
- 你认为下一步应点哪里？

通过候选线：至少80%能说出“帮助找到独特性并转为事业系统”的近义表达。

### 任务二｜90秒入口

给出一个真实症状，要求找到起点。

观察：

- 是否选择正确A/B/C入口；
- 是否犹豫超过10秒；
- 是否把媒体阅读入口误当作行动入口；
- 是否理解导航结果只是待验证假设。

### 任务三｜3—10分钟完成

完成原力导航或一个推荐工具，回答：

- 你得到了什么？
- 下一步是什么？
- 哪句话不清楚或不可信？

### 任务四｜回访连续性

关闭并重新打开首页，观察是否发现“继续上次进度”，能否回到正确位置。

## 7. 指标与状态

真人测试前全部保持：

```text
首次理解效率：NOT_RUN
入口选择正确率：NOT_RUN
导航完成率：NOT_RUN
推荐工具点击率：NOT_RUN
工具完成率：NOT_RUN
回访连续性：NOT_RUN
```

页面、代码和本地状态存在只允许标记 `Done`。

达到 `Validated` 至少需要：

- 真人完成真实任务；
- 结果可观察；
- 误判与反例被记录；
- 有权人类完成裁决。

达到 `Compounding` 至少需要：

- 从测试或Outcome形成Changed Rule；
- Task2开始前明确加载该规则；
- 第二次行动出现可观察变化。

## 8. WIP限制

在首次成功测试通过前：

- 不新增一级栏目；
- 不新增核心内容类型；
- 不建设账户系统；
- 不扩展到复杂推荐算法；
- 导航题目改动每轮不超过3项；
- 同时运行的真人测试版本只有1个。

## 9. 禁止事项

- 不把3分钟导航称为经验证诊断；
- 不用页面点击替代Outcome；
- 不让AI自动批准正典或Changed Rule；
- 不把私密答案写入公开仓；
- 不用“米奇十戒通过”替代真人可用性证据；
- 不为了降低认知负担而删除证据等级、反例和边界。
