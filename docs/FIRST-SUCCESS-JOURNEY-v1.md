# 门户首次用户成功旅程 v1.1

- 状态：`execution-ready / evidence NOT_RUN`
- 适用仓：`moonstachain/yuanli-strategy-web`
- 上位边界：Soul 管法；Web 只做公开安全投影、用户行动入口和必要本地状态
- 北极星：陌生专家型创业者在首次访问中完成一项有价值的行动，并知道下一步

## 1. 核心裁决

```text
看见我
→ 理解我
→ 定位我
→ 帮我完成一次
→ 记住我做到哪里
```

完整价值链：

```text
前沿信号
→ 真实症状
→ 3分钟原力导航
→ 唯一下一步
→ 工具形成资产
→ 现实行动与Outcome
→ Changed Rule候选
→ Task2复用
```

## 2. 用户入口

一级用户入口冻结为：

```text
看时代 / 找原力 / 做生意 / 建系统 / 文章 / 案例 / 工具 / 正典
```

主题、栏目、战役、旗舰、发布状态、回写协议进入“关于我们如何工作”。

## 3. 首页合同

首次访问必须满足：

1. 首屏只有一个主要行动：`开始3分钟原力导航`；
2. 次行动只承担解释，不与主行动同级；
3. 第二屏只展示A/B/C真实症状；
4. 用户问题在前，正典坐标在后；
5. 工具先说收益与下一步；
6. 文章搜索只在文章中心；
7. 建设状态和证据纪律后移但可达；
8. 有历史状态时提供“继续上次进度”。

## 4. 3分钟原力导航 v0.2

### 作用域

```text
全面导航：9题
找原力 A：3题
做生意 B：4题
建系统 C：2题
```

每种作用域独立计算题号、分母和完成百分比。

### 历史冲突

如果用户上次保存的是A，本次明确点击B或C，系统不得自动覆盖本次意图，也不得自动丢弃历史进度。必须展示两个动作：

- 继续上次进度；
- 按这次选择开始。

### 并列结果

并列最高分必须显式展示。首个建议按照A→B→C的上游优先原则给出，并告诉用户为什么；不得暗中默认后置模块。

### 输出

- 一个优先验证坐标；
- 判断依据；
- 并列位置说明（如有）；
- 一个唯一下一步；
- 明确边界。

状态始终是 `navigation hypothesis`，不是人格测评或经验证诊断。

## 5. 工具连续性

工具统一保存：

```text
fields
final_generated_asset
updated_at
next_action_context
```

进度只计算用户真实填写/改动的字段。下拉框默认值不计入完成进度。

四种财富诊断卡属于综合诊断，必须提示“建议完成基础导航后使用”。

## 6. 阅读连续性

文章必须支持：

- 当前路径；
- 文章/案例中心返回；
- 同源访问时“返回上一页”；
- 证据等级与来源状态；
- 移动端保留证据说明；
- 具体CTA，不使用泛化“进入下一步”。

## 7. 纸—场—舱连续性

三态都必须显示当前任务空间：

- 阅读模式｜理解机制与证据；
- 观察模式｜看时代与结构；
- 工作模式｜完成判断与行动。

三态是同一产品的不同工作空间，不是三个独立站点。

## 8. 真人测试

样本：5—8位目标用户。

### 30秒理解
回答：这个网站做什么、与我有什么关系、下一步点哪里。

### 90秒入口
观察：是否选择正确A/B/C入口、是否犹豫、是否误把媒体入口当行动入口。

### 3—10分钟完成
完成导航或推荐工具，回答：得到了什么、下一步是什么、哪句话不清楚或不可信。

### 回访连续性
关闭并重新打开首页，观察是否能发现“继续上次进度”并回到正确位置。

## 9. 状态纪律

真人测试前继续保持：

```text
首次理解效率：NOT_RUN
入口选择正确率：NOT_RUN
导航完成率：NOT_RUN
推荐工具点击率：NOT_RUN
工具完成率：NOT_RUN
回访连续性：NOT_RUN
```

工程存在只允许标记 `Done`。

## 10. WIP与禁止事项

在首次成功测试通过前：

- 不新增一级栏目；
- 不新增核心内容类型；
- 不建设账户系统；
- 不扩展复杂推荐算法；
- 同时运行的真人测试版本只有1个；
- 不把导航称为Validated诊断；
- 不用点击替代Outcome；
- 不把私密答案写入公开仓；
- 不以专家审计替代真人可用性证据。
