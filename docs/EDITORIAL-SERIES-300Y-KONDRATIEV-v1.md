## 1. 总裁决

这个栏目不是讲宏观经济，也不是复述工业革命史，而是：

> **从一个具体年份、一件物品、一场事故或一次关键决策切入，看懂技术、资本、制度、组织与个人命运如何同时换轨。**

每篇最终回答一个与今天有关的问题：

> 当一个时代的通用能力被机器平权以后，什么能力开始升值？普通人和创业者该如何重新安排自己的原力？

对应三部曲：

```text
原力资产：时代变化后，什么能力变得稀缺？
原力创业：什么新品类、链路和控制权开始形成？
原力 OS：新时代的有效经验如何被保存和继承？
```

栏目正式定位：

# 原力时代志

第一季名称：

# 《300年康波：24个改写个人命运的时代时刻》

副标题：

> 从一座工厂、一列火车、一封电报、一辆汽车、一枚芯片、一个聊天框，看懂时代如何更换操作系统。

## 2. 学术与表达边界

对外可以使用“300年康波”作为传播语言，对内采用更稳健的研究骨架：

```text
技术革命
→ 资本安装
→ 基础设施扩张
→ 制度适配
→ 社会扩散
→ 个人与组织命运重排
```

禁止宣称：

- 每隔固定年数必然发生某种事件；
- 某一年必然进入某个康波季节；
- 仅凭周期位置即可预测资产价格；
- 历史结构同构等于历史结果必然重复。

栏目使用历史的目的，不是预测下一个风口，而是识别选择环境如何变化，以及能力、财富、组织与控制权如何重新分配。

## 3. “小切口，大纵深”选题公式

一个合格切口必须同时满足四项：

### 3.1 看得见

优先选择具体物品、场景或决策：

- 一座工厂；
- 一场火车竞赛；
- 第一封电报；
- 一辆 Model T；
- 一条流水线；
- 一间酒店；
- 一艘集装箱船；
- 一枚芯片；
- 一台个人电脑；
- 一部手机；
- 一个聊天框。

### 3.2 装得下

小事件必须能够压缩一个时代的主要矛盾：

- 手艺人与机器；
- 距离与速度；
- 信息与判断；
- 发明与基础设施；
- 金融与实体生产力；
- 技术与制度；
- 效率与人的主体性。

### 3.3 照得到今天

每篇必须建立“今天的回声”，但同时说明类比边界：

```text
纺织机器 ≈ 生成式 AI
铁路网 ≈ 算力与 Agent 基础设施
电网 ≈ AI 操作系统
流水线 ≈ 自动化工作流
大众品牌 ≈ 平台与个人 IP
```

这里的“≈”只表示结构参照，不表示事实、速度、制度与结果完全相同。

### 3.4 落得回原力战略

每篇至少回答：

1. 什么旧能力被平权了？
2. 什么新能力变稀缺了？
3. 新的选择环境是什么？
4. 谁获得了品类、基础设施、入口或留存控制权？
5. 新职业、新企业和新品类如何出现？
6. 普通人应该追逐工具，还是重建生成源？
7. 有效经验如何进入下一轮资产与 OS？

## 4. 300年24个选题母库

这不是24篇独立的历史文章，而是六幕连续的文明故事。

### 第一幕｜资本先于生产力奔跑（1720—1771）

| 时刻 | 小切口 | 大纵深 |
|---|---|---|
| 1720 | 南海泡沫 | 为什么大时代经常先出现资本幻觉 |
| 1733 | 飞梭 | 一个小工具如何打破旧生产链平衡 |
| 1769 | 瓦特蒸汽技术 | 发明为什么不等于商业革命 |
| 1771 | 克罗姆福德水力纺织厂 | 工厂如何重定义时间、劳动和组织 |

原力母题：

> 大时代真正淘汰的，往往不是一个职业，而是一套旧的价值生产方式。

### 第二幕｜世界开始提速（1807—1844）

| 时刻 | 小切口 | 大纵深 |
|---|---|---|
| 1807 | 商业蒸汽船 | 能源如何改变地理和交易半径 |
| 1825 | 第一条现代公共铁路 | 基础设施如何创造此前不存在的市场 |
| 1829 | “火箭号”铁路竞赛 | 速度如何从技术指标变成商业模式 |
| 1844 | 第一封远距离电报 | 信息第一次比人和货物移动得更快 |

原力母题：

> 当信息和执行越来越快，速度还是壁垒，还是判断开始成为真正的稀缺品？

### 第三幕｜世界成为一个市场（1851—1882）

| 时刻 | 小切口 | 大纵深 |
|---|---|---|
| 1851 | 伦敦万国工业博览会 | 技术如何成为国家叙事和社会信仰 |
| 1869 | 苏伊士运河 | 一个通道如何重写全球产业链 |
| 1875 | 钢铁大规模生产 | 竞争如何从手艺升级为基础设施 |
| 1882 | 珍珠街发电站 | 爱迪生真正卖的为什么不是灯泡而是电网 |

原力母题：

> 一个伟大的单品，什么时候会升级为改变所有行业的通用基础设施？

### 第四幕｜大规模生产与大规模社会（1908—1944）

| 时刻 | 小切口 | 大纵深 |
|---|---|---|
| 1908 | Ford Model T | 如何把少数人的奢侈品变成大众市场 |
| 1913 | 移动装配线 | 十倍效率如何同时创造繁荣和人的异化 |
| 1929 | 华尔街崩盘 | 为什么金融总是比制度跑得更快 |
| 1944 | 布雷顿森林会议 | 技术黄金时代为什么需要制度接住 |

原力母题：

> 十倍好不是把旧产品做得更奢华，而是通过模式创新，让原本无法使用的人开始使用。

### 第五幕｜世界被编码（1947—1971）

| 时刻 | 小切口 | 大纵深 |
|---|---|---|
| 1947 | 晶体管 | 智能如何从大型机器走向微型化 |
| 1956 | Ideal-X 集装箱船 | 标准接口为什么比更快的船更重要 |
| 1969 | ARPANET 四节点网络 | 网络为何从通信工具变成社会基础设施 |
| 1971 | Intel 4004 微处理器 | 通用可编程能力如何吞噬专用硬件 |

原力母题：

> 真正改变世界的往往不是一个更强的产品，而是一个让无数产品重新组合的标准接口。

### 第六幕｜个体成为节点，智能成为基础设施（1981—2022）

| 时刻 | 小切口 | 大纵深 |
|---|---|---|
| 1981 | IBM PC | 计算能力如何从组织中心走向个人桌面 |
| 1995 | 互联网商业化 | 流量、平台与网络效应如何成为新控制权 |
| 2007 | iPhone | 一个入口如何重写十几个行业 |
| 2022 | ChatGPT | 语言为什么成为人机协作的新操作界面 |

原力母题：

> 当语言、知识和执行都成为公共算力，一个人还能凭什么拥有不可复制性？

## 6. 每篇文章固定“八层纵深”

1. **现场**：用150—300字让读者进入当时的具体场景；
2. **旧世界的合理性**：解释当时的人为什么没有立刻看懂；
3. **真正突破**：拆解技术、能源、基础设施、标准接口、资本与组织制度；
4. **能力贬值**：哪些技能、资源或旧优势突然变廉价；
5. **能力升值**：哪些判断、组织、标准、品类和关系能力开始变贵；
6. **新时代主人公**：新职业、新企业和新人物类型如何形成；
7. **中国镜像**：同一时间中国发生什么，普通人的职业与生活如何变化；
8. **今天的原力行动**：结尾生成一个可回写产物，而不是只留下感慨。

可选行动产物：

- AI清算卡；
- 时代势能地图；
- 旧能力贬值清单；
- 新稀缺能力清单；
- 品类重定义句；
- 三条链路变化图；
- 四大控制权地图；
- 原力OS回写卡。

## 7. 每篇固定“原力五问”

### 第一问：这次革命平权了什么？

对应 A1：哪些过去昂贵、稀缺、需要多年训练的能力开始成为公共能力？

### 第二问：它重新奖励了什么？

对应 A3：什么判断、品味、关系、组织和行动能力开始升值？

### 第三问：新的选择环境是什么？

对应 B1：宏周期势、中结构势、微入口势与合力匹配如何变化？

### 第四问：新的控制权落在谁手里？

对应 B2—B4：谁定义品类，谁控制基础设施、入口、数据、关系和留存？

### 第五问：有效经验如何进入下一代？

对应 C1—C4：为什么一些组织只是踩中红利，而另一些组织能把红利变成文脉、知识、能力、流程与下一轮起点？

## 8. 栏目的价值高弧光

每次时代革命都会让一批能力变得廉价，也会让另一批人类价值更加稀缺。

AI可能快速平权：

```text
标准答案
标准表达
标准分析
标准执行
标准模仿
```

同时让以下能力升值：

```text
决定什么值得做
看见尚未被命名的问题
承担真实后果
形成独特品味
建立可信关系
创造新的选择标准
把经验写成可进化系统
```

栏目不是借历史预测下一个风口，而是借历史识别：

> 当世界再次更换操作系统时，我身上什么必须被放弃，什么必须被守住，什么必须被重新训练，什么必须被写成系统。
