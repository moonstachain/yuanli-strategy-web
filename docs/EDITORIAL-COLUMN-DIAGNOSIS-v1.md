# 原力诊断室 v1.0

- 状态：`accepted / planning-baseline`
- 栏目层级：常设栏目
- 正典接口：A1—C4
- 最高纪律：诊断不是贴标签，不把一次访谈写成结论，不公开未经授权的可识别信息。

---

## 1. 栏目定位

> 从一个创业者正在经历的真实症状进入，区分表面问题、真正贵任务、错误用力和最小下一步，判断他更可能卡在三部十二模块的哪里。

栏目不负责给出宏大人生答案，而是完成：

```text
用户原话
→ 症状还原
→ 竞争性解释
→ 原力坐标
→ 一个关键裁决
→ 一个最小动作
→ 30天后结果
```

---

## 2. 每期固定“诊断七步”

1. **用户原话**：保留其自己的表达，不先替换为原力术语；
2. **现实损失**：问题正在造成什么金钱、时间、风险、能量或关系代价；
3. **三个竞争性解释**：至少保留两个可能推翻主诊断的替代解释；
4. **原力坐标**：标注最可能的主模块与相关模块；
5. **错误用力**：用户目前做得更多但可能让问题恶化的动作；
6. **最小实验**：7—30天内可执行、可观察、可停止的行动；
7. **回访与改判**：依据Action、Evidence和Outcome更新诊断。

---

## 3. 诊断不是测评结果

必须区分：

- `symptom`：用户正在经历什么；
- `hypothesis`：当前最高可信解释；
- `evidence`：什么支持或反对该解释；
- `action`：用户真实采取了什么；
- `outcome`：现实发生了什么变化；
- `changed diagnosis`：是否需要改判。

没有回访时，最多标为 `hypothesis / action proposed`，不得标为验证成功。

## 4. 首批12个诊断题

1. 内容做了三年，市场仍不知道你代表什么；
2. 有很多能力，却说不清真正不可复制的源头；
3. 用户都说喜欢，但很少有人愿意付钱；
4. 产品很多，却没有一个清晰品类；
5. 流量增加，利润和现金反而下降；
6. 团队人数增加，创始人却越来越忙；
7. SOP越来越多，交付质量仍然漂移；
8. AI提高了产量，品牌却越来越不像本人；
9. 项目很多，每次仍从零开始；
10. 高客单价成立，但复购和转介绍很弱；
11. 创始人有强判断，团队却无法继承；
12. 机会很多，但事业越来越耗能。

## 5. 公开与隐私门

进入公开栏目必须满足：

- 明确授权；
- 删除姓名、公司、联系方式与可逆推出身份的组合信息；
- 不公开私密经营真账；
- 不发布未经确认的心理、健康或人格推断；
- 当事人有权审阅事实段；
- 诊断意见与事实明确分层；
- 结果不佳、未行动和拒绝同样保留。

## 6. 第一篇试点

# 《内容做了三年，为什么市场仍不知道你代表什么？》

竞争性解释候选：

1. A1问题：差异生成源尚未清楚；
2. A4问题：独特性没有被外部稳定识别；
3. B2问题：用户选择标准和心理账户没有形成；
4. B4问题：平台流量存在，但心智控制权和入口控制权不足。

最小行动候选：

- 选择10名甜用户；
- 记录他们如何无辅助复述你；
- 同时测试两个竞争性品类假设；
- 观察是否发生咨询、转介绍、预算或其他真实行动；
- 7—14天后更新诊断。

---

## 7. Outcome Question

> 用户是否在真实任务中执行了最小动作，并产生足以支持、削弱或推翻原诊断的证据？
