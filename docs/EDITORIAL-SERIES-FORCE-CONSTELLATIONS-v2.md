## 1. 版本裁决

上一版的问题不是框架错误，而是选材仍停留在“伟人名单”层面：

```text
先选公认伟人
→ 找代表成就
→ 再套入原力母体
```

这种方式会导致：

1. 人物太正确，读者提前知道结局；
2. 故事太完整，没有真正的命运分岔；
3. 原力母体变成对成功者的事后解释；
4. 只讲成功显化，忽略正确判断为何没有形成共识或行动；
5. 只见光，不见阴影、协作者、制度条件和偶然性。

v2.0 改为：

> **不写伟人传记，写命运临界点。**

真正精妙的群星时刻，不是一个人后来取得了多大成就，而是：

> **在证据不完整、结果不可知、代价真实存在时，一个人为何作出与多数人不同的选择？**

原力母体在此不是“伟人天赋”，而是一种跨时间反复出现的选择函数：

- 他反复注意什么；
- 对什么低级答案无法容忍；
- 用什么标准裁决；
- 愿意为哪种结果支付代价；
- 在外部答案失效时，什么仍然不能被背叛。

# 2. 栏目定位

## 总栏目

# 原力群星志

## 第一季正式名称

# 《世界差一点走向另一条路》

副标题：

> **12个群星临界时刻：一个判断、一项拒绝、一次公开、一场未被相信的作证，如何改变人类的下一步。**

栏目唯一承诺：

> 不证明“伟人拥有强大的原力”，而是揭示：当时代尚未给出答案时，一个人最后依据什么作出选择；这个选择又如何被世界拒绝、接纳、制度化或遗忘。

栏目与《300年康波》的关系：

```text
《300年康波》
以时代为主人公
回答：世界为什么在那个时刻换轨？

《世界差一点走向另一条路》
以命运临界点为主人公
回答：为什么偏偏是这个人，在结果未知时作出了不同选择？

原力工具
以今天的读者为主人公
回答：这一次历史选择，要求我现在完成什么判断与行动？
```

共同母命题：

> **时代提供选择环境，原力母体生成独特回应，原力 OS 决定回应能否成为后人的下一次输入。**

# 3. 什么才算“群星临界时刻”

一个候选故事至少包含：

```text
一个具体现场
× 一个无法忽视的异常
× 两种都具有合理性的选择
× 结果在当时不可知
× 真实代价
× 公共后果
× 跨时间遗产或失败教训
```

它通常表现为：

```text
他本可以不看见
他本可以随大流
他本可以继续等待
他本可以保持沉默
他本可以批准
他本可以申请专利
他本可以只保护自己
但他没有
```

## 原力解释边界

不得把历史人物强行证明为“原力战略学员”。

A1—C4 只是一套解释工具，用于识别：

- 差异生成源如何显形；
- 时代选择环境如何作用；
- 判断如何进入语言、作品、制度和组织；
- 正确判断为何可能显化失败；
- 有效经验如何被保存、复用或丢失。

必须允许以下结论：

- 某个模块没有成立；
- 正确判断没有进入共识；
- 个人原力没有形成组织能力；
- 伟大公共贡献伴随严重个人阴影；
- 一次闪耀没有形成长期复利；
- 没有此人，历史可能只是延迟或改道，而非完全不发生。

# 4. 人物与故事的六道编辑门

一位人物进入栏目，必须同时通过六道门。

## 第一门｜一个极小现场

最好能压缩为：

- 一张办公桌；
- 一只水泵把手；
- 一次雪地散步；
- 一页古方；
- 一份药品申请；
- 一间隔离病房；
- 一份写着评语的提案；
- 一本决定是否公开的技术书。

## 第二门｜至少两种选择都具有合理性

不能是“好人选择善、坏人选择恶”。

应该是：

- 服从制度，还是承担越权风险；
- 等待理论完整，还是先阻止伤害；
- 保守技术秘密，还是公开知识；
- 争夺个人荣誉，还是推进共同发现；
- 保护自己，还是继续接近危险；
- 接受行业惯例，还是坚持更高证据标准。

## 第三门｜结果在当时不可知

人物不能因为知道自己会赢才作出选择。

## 第四门｜选择支付真实代价

代价可以是：

- 职位；
- 荣誉；
- 财富；
- 安全；
- 身体；
- 关系；
- 时间；
- 被误解；
- 长期孤独。

没有成本，不能证明长期承诺。

## 第五门｜既有光，也有未完成

必须呈现：

- 错误；
- 盲点；
- 阴影；
- 表达失败；
- 协作者贡献；
- 制度条件；
- 偶然与运气；
- 后见之明偏差。

## 第六门｜形成公共遗产或公共失败

至少产生一种：

- 制度；
- 科学规则；
- 方法；
- 基础设施；
- 公共知识；
- 组织能力；
- 反例；
- 后人继续调用的实践。

# 5. 第一季人物池 v2.0｜12种原力命运

以下全部为 `editorial candidate`。人物、年份、因果和细节在进入写作前必须建立独立事实包，不得把策划稿当作历史证据。

## 第一幕｜看见了，但世界还没有语言

### 01｜1847：杀死产妇的，可能正是医生自己

- 人物候选：伊格纳兹·塞麦尔维斯
- 极小现场：医生从尸检室进入产房；一位同事因尸检划伤后死亡。
- 命运悖论：一个能显著降低死亡的判断，为什么因触犯医生身份认同而难以被接受？
- 原力命题：

```text
有事实
≠ 有解释
≠ 有共识
≠ 有组织行动
```

- 主要模块：A3、A4、B2、C1、C4
- 今天的回声：《为什么很多创始人的正确判断，团队就是执行不了？》
- 行动候选：判断—共识—执行断点图
- 事实包重点：死亡率数据、洗手方案、接受阻力、表达与人格争议、巴斯德时代关系。

### 02｜1854：细菌尚未被证明，他先拆掉了一只水泵把手

- 人物候选：约翰·斯诺
- 极小现场：一张死亡地图与一只公共水泵把手。
- 命运悖论：理论尚未完整，一个人什么时候可以依据“足够好的证据”采取公共行动？
- 原力链路：

```text
观察
→ 地图
→ 异常点
→ 访谈
→ 行动
```

- 主要模块：A3、B1、C2、C3、C4
- 今天的回声：《AI时代，我们需要更多答案，还是更好的证据结构？》
- 行动候选：事实—推论—行动阈值卡
- 事实包重点：病例地图是否为唯一决定因素、地方委员会行动、泵把手拆除时间、疫情自然消退争议。

## 第三幕｜最大的贡献，是一道没有打开的门

### 05｜1960：她没有批准一款药，因此避免了一场灾难

- 人物候选：弗朗西丝·凯尔西
- 极小现场：一张办公桌、一份申请、一家持续施压的药企。
- 命运悖论：她没有证明药物一定有害，只判断“证据还不够”；为什么拒绝也可以是一种创造？
- 原力命题：

> 真正的判断力，不仅表现为做成什么，也表现为在所有人催促时仍知道什么不能做。

- 主要模块：A2、A3、B4、C1、C3、C4
- 今天的回声：《AI越强，我们越需要一个有权说“不”的人》
- 行动候选：Human Gate 决策卡
- 事实包重点：申请时间线、审评权限、药企往来、美国市场实际暴露、灾难归因边界、后续制度变化。

### 06｜1993：为什么把一项可能垄断世界的技术交给所有人？

- 人物候选：蒂姆·伯纳斯-李与 CERN 团队
- 极小现场：一份被评价为“模糊，但令人兴奋”的提案；一次将软件置于公共领域的决定。
- 命运悖论：放弃部分所有权，为什么反而可能形成更大的世界级基础设施？
- 原力命题：

```text
占有不一定产生最大控制权
开放协议也可能生成更强生态位
```

- 主要模块：B2、B3、B4、C1—C4
- 今天的回声：《哪些原力资产应该收费，哪些协议必须开放？》
- 行动候选：资产开放—收费边界卡
- 事实包重点：Web前置技术、CERN组织决策、许可时间线、其他互联网参与者、开放与后续平台垄断的悖论。

# 7. 每篇固定使用“命运九场”

## 第一场｜一切看起来都很正常

还原旧世界的合理性，禁止用后见之明嘲笑当时参与者。

## 第二场｜出现一个不协调的细节

一组死亡数据、一个异常病人、一句古方、一份缺失实验、一项证据不足的申请。

## 第三场｜只有他无法忽视

从异常进入长期注意力与原力母体候选，但必须使用假设语言：

> 当前最能解释其跨时期判断与选择的母体假设是……

同时列出支持证据、反证和未解释部分。

## 第四场｜旧身份受到威胁

如果判断成立：

- 医生可能正在伤害病人；
- 行业标准可能是错的；
- 已上市产品可能不安全；
- 自己的发现可能被用于战争；
- 商业秘密可能不该继续封闭。

## 第五场｜出现命运分岔

必须呈现至少两种当时都合理的选项。

## 第六场｜他作出了选择

不是因为知道结局，而是依据某种不能背叛的判断结构。

## 第七场｜世界没有立刻奖励他

呈现拒绝、误解、失去荣誉、疾病、沉默、失败或行动断裂。

## 第八场｜结果进入公共系统

回答是否形成：

- 新制度；
- 新方法；
- 新语言；
- 新实验；
- 新基础设施；
- 新组织能力；
- 后人可复用资产。

## 第九场｜留下一个今天仍未完成的问题

不得用“我们要学习他的精神”收尾。

必须落为：

> 今天的你，正在回避哪个已经被自己看见的事实？

并连接一张行动卡。

# 8. 原力群星六问

每篇至少回答：

1. **他真正不可复制的是什么？**不是技能清单，而是什么结构持续生成了判断与选择。
2. **这种原力从哪里来？**生命经历、长期注意、品味、关系和责任如何塑造它。
3. **时代为什么在此刻需要它？**母体如何与时代选择环境相遇。
4. **他作出了什么高代价选择？**如何证明这不是兴趣或自我包装。
5. **它如何变成公共成果，或为什么没有变成？**语言、组织、制度、产品与行动链路在哪里断裂。
6. **它如何在本人之后继续生长？**文脉、记忆、地图、链路、后人修正与反例如何形成。

# 9. 事实与叙事治理

## 9.1 五层事实标注

每篇素材必须区分：

```text
F1｜确定事实
F2｜当事人原话或同时代记录
F3｜权威后世解释
I1｜编辑推论
N1｜文学化重构
```

不得把 I1 或 N1 写成 F1。

## 9.2 事实包最低字段

```yaml
story_id:
person_or_team:
critical_moment:
date_range:
scene:
primary_sources:
authoritative_secondary_sources:
disputed_claims:
reasonable_alternatives:
collaborators_and_institutions:
choice_options:
cost_paid:
public_consequence:
counterfactual:
force_mother_hypothesis:
supporting_evidence:
disconfirming_evidence:
shadow_and_unfinished:
A1_C4_mapping:
today_echo:
related_tool:
outcome_question:
reviewers:
status:
```

## 9.3 反事实纪律

反事实必须回答：

- 此人真正改变了哪个变量；
- 哪些力量不是他创造的；
- 没有此人，事情更可能延迟、改道还是失败；
- 个人、团队、组织、制度和时代分别贡献了什么。

禁止使用“一个人拯救了世界”式未经支持的表达。

## 9.4 原力母体纪律

母体只能标为 `hypothesis`，不能写成：

- 灵魂真相；
- 天命；
- 单一人格标签；
- 一次成功的事后解释。

必须包含：

- 跨时期证据；
- 反证；
- 阴影版本；
- 情境依赖；
- 仍无法解释的部分。

## 9.5 B4纪律

只使用最新四种控制权：

- 虚：心智控制权；
- 实：交付控制权；
- 入：入口控制权；
- 出：留存控制权。

飞轮是强化机制，母体是生成源，不作为第五、第六壁垒并列。

# 10. 第一篇试点｜凯尔西与 Human Gate

## 正式候选标题

# 《1960：她没有批准一款药，因此避免了一场灾难》

## 今天的回声

# 《AI越强，我们越需要一个有权说“不”的人》

## 故事装置

```text
一张办公桌
一份药品申请
一家不断施压的公司
一项已在多个市场使用的药物
一个没有证明它必然有害的审评员
一句：证据还不够
```

## 大纵深

```text
判断力是什么
→ 专业责任是什么
→ 为什么拒绝也是创造
→ Human Gate为何存在
→ 效率与安全如何冲突
→ 一次判断如何升级为制度阈值
→ AI时代谁来守最后一道门
```

## 模块映射

- A2：什么不因速度、压力和机会交换；
- A3：证据判断能力如何形成；
- B4：制度阈值如何形成控制权；
- C1：不可越过的价值与风险边界；
- C3：什么条件决定继续、停止或升级；
- C4：批准权、Stop条件、Fallback与回写。

## Human Gate 决策卡 v0.1

1. 这是事实、推论，还是模型生成？
2. 证据缺失在哪里？
3. 错误发生后，谁承担后果？
4. 哪些条件没有满足就不能继续？
5. 外部速度压力是否正在降低判断标准？
6. 这次拒绝应该沉淀成什么制度阈值？

## Outcome Question

> 读者是否在一个真实AI或经营决策中，明确设置了至少一个Stop条件、一个有权批准人和一条可回写的制度阈值？

## 首篇发布门

- [ ] 完成独立历史事实包；
- [ ] 至少一项一手或同期记录；
- [ ] 至少两项权威二手来源；

- [ ] 完成与AI Human Gate的同构和失效边界；
- [ ] 完成专业事实审阅；

# 最终裁决

新版栏目不是：

```text
伟人
→ 成就
→ 品格
→ 原力解释
```

而是：

```text
正常世界
→ 一个异常
→ 身份冲突
→ 命运分岔
→ 高代价选择
→ 世界拒绝或接纳
→ 公共遗产或公共失败
→ 今天轮到我们选择
```

《300年康波》写的是：

> **时代如何换轨。**

《世界差一点走向另一条路》写的是：

> **在时代尚未给出答案时，一个人如何成为那个转向点。**

原力战略最终要帮助今天的读者回答：

> **在所有外部答案都不可靠的时刻，我最后依据什么作出选择；这次选择又如何成为下一代仍能使用的资产？**
