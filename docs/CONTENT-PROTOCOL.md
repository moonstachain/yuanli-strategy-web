# 内容生产与治理协议 v0.1

## 1. 内容的第一性目标

文章不是为了填满网站，而是完成一次心智加工：

```text
现实症状
→ 旧有解释
→ 认知冲突
→ 第一性问题
→ 原力裁决
→ 模块坐标
→ 案例或反例
→ 最小行动
→ 证据与回写候选
```

最低验收：读者完成一个判断、一个动作，或留下一个可见资产。

## 2. 五类文章

| 类型 | 任务 | 主要证据 |
|---|---|---|
| insight | 从外部事件进入时代机制 | 可核验外部来源＋明确推论 |
| canon | 讲透稳定概念和边界 | Soul 正典引用 |
| case | 展示真实对象如何发生 | Baseline、Action、Outcome、反例 |
| tool | 帮用户完成一个动作 | 输入、步骤、输出、验收 |
| library | 将经典学科翻译为原力视角 | 原始/权威来源＋边界声明 |

## 3. Front Matter 必填字段

- `trilogy` / `module`：归属正典位置；
- `theme`：用户前台入口；
- `articleType`：内容任务；
- `userSymptoms`：用户原话或可识别症状；
- `expensiveJob`：文章帮助完成的贵任务；
- `coreConcepts`：稳定概念；
- `evidenceLevel`：hypothesis / derived / verified / canon；
- `canonStatus`：public_projection / canon_aligned / canon_candidate；
- `nextAction`：读后下一步。

## 4. 证据纪律

- `canon`：由 Soul 正典明确支持；
- `verified`：存在可核验的事实、行动或有权人类确认；
- `derived`：基于证据的分析与推论，必须标明推论；
- `hypothesis`：待检验假设，不得写成既成事实。

Output 不等于 Outcome。页面上线、工具存在、用户点赞均不能单独证明业务结果。

## 5. B4 最新口径

壁垒只使用四种控制权：

- 虚：心智控制权；
- 实：交付控制权；
- 入：入口控制权；
- 出：留存控制权。

飞轮是四权相互强化的动态结果，母体是生成源，不作为第五、第六壁垒并列。

## 6. 隐私与公开边界

禁止进入本仓：

- Founder 完整私密身份与敏感经历；
- 客户可识别隐私、原始对话和未授权材料；
- 凭证、密钥、内部经营真账；
- 未经确认的敏感推断。

案例必须脱敏、授权并标注证据成熟度。

## 7. 发布门

文章从 draft 进入 published 前必须满足：

1. 标题承诺与正文一致；
2. 正典术语无漂移；
3. 事实、分析、假设可区分；
4. 至少一个反例或边界；
5. 有清晰的下一步行动；
6. 内链与外链可访问；
7. 不越过 Web 的法权边界。
