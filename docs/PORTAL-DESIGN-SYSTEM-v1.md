- 状态：`accepted / implementation-baseline`
- 上游设计正本：`moonstachain/yuanli-taste`
- 适用仓库：`moonstachain/yuanli-strategy-web`
- 上位体验合同：`docs/FIRST-SUCCESS-JOURNEY-v1.md`
- 交互一致性合同：`docs/UX-CONSISTENCY-CONTRACT-v1.md`

## 1. 核心裁决

门户继续保留“纸—场—舱”三态，但**首次成功旅程高于页面展示密度**。

```text
用户任务与首次成功
> 页面编排
> 视觉场景
> 组件外观
```

旧版“首页高密度总控台”合同正式废止。以下内容不得再作为首页强制结构：

- A1—C4完整矩阵；
- 七栏目状态总账；
- 四旗舰完整总览；
- 文章多维筛选器；
- 主题/栏目/战役/旗舰的建设者分类。

这些内容可以存在，但必须进入正典、文章中心或“关于我们如何工作”。

## 2. 用户可见信息架构

一级用户入口冻结为：

```text
看时代
找原力
做生意
建系统
文章
案例
工具
正典
```

一级导航回答“我来这里做什么/找什么资产”，不得混入建设者分类。

建设者信息统一进入“关于我们如何工作”：

```text
主题
栏目
战役
旗舰
发布状态
回写协议
```

## 3. 纸—场—舱三态

### Paper｜阅读模式
适用：文章、案例、正典、书房、关于。
目标：理解机制、证据与边界。

### Field｜观察模式
适用：首页、前哨、旗舰观察场。
目标：看见时代、结构、位置与选择。

### Cockpit｜工作模式
适用：3分钟导航、工具、诊断室、OS实验室。
目标：完成判断、形成资产、保存进度并进入现实验证。

三态必须共享：Header位置、品牌标识、主按钮语法、页面标题比例、模式提示、返回路径、Footer信任语言。

## 4. 首页合同

首页固定优先级：

```text
母叙事＋一个主行动
→ A/B/C真实症状
→ 当前封面故事
→ 原力前哨
→ 行动工具
→ 阅读轨道
→ 商业物种
→ 三阶段地图
→ 证据与边界
```

首页负责推荐，不负责展示完整数据库。

## 5. 组件与交互合同

- `.button primary`：唯一主要行动；
- `.yl-card`：统一卡片材料；
- `EvidenceBadge`：证据等级；
- `ModuleCoordinate`：A1—C4精确坐标；
- `ActionPanel`：读后具体行动；
- `.progress-track`：导航与工具真实进度；
- `mode-strip`：解释当前处于观察/阅读/工作哪一种任务空间；
- `localStorage`：仅保存本地草稿、生成资产与继续位置。

CTA统一使用可预测动作：

```text
阅读这篇文章
找到我的起点
开始完成这张卡
进入现实验证
继续上次进度
返回上一页
```

禁止使用没有信息量的“点击查看”“进入下一步”作为默认按钮。

## 6. 导航一致性

- `/start/?path=A` 只高亮“找原力”；
- `/start/?path=B` 只高亮“做生意”；
- `/start/?path=C` 只高亮“建系统”；
- A/B/C分别按3/4/2题计算自己的进度；
- 历史进度与当前入口冲突时，必须让用户选择；
- 并列结果必须显式展示，不得暗中优先后置模块。

## 7. 工具连续性

- 默认下拉值不计入完成进度；
- 输入与最终生成资产都保存到当前浏览器；
- “清空当前内容”和“删除已保存草稿”语义必须区分；
- 综合诊断工具必须标明前置条件，不与首次使用工具无差别平铺。

## 8. 阅读连续性

- 移动端必须保留证据等级与来源状态；
- 文章必须显示当前位置；
- 同源访问时提供“返回上一页”；
- 文末提供具体下一步和返回文章/案例中心；
- 案例作为文章中心稳定筛选入口，不依赖栏目总览。

## 9. 无障碍与移动端

必须继续覆盖：键盘焦点、fieldset/legend、aria-live、reduced-motion、长中文标题、390×844与375×667，以及Sticky元素不遮挡结果。

## 10. 真实性边界

工程通过只能证明 `Done`。

以下仍必须保持 `NOT_RUN`，直到真人证据存在：

- 30秒理解率；
- 90秒入口正确率；
- 导航完成率；
- 工具完成率；
- 回访连续性；
- 真实Outcome；
- Changed Rule；
- Task2复用。
