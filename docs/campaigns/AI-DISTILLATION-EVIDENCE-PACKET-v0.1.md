## 2. 来源优先级

1. 企业官方产品说明、工程博客、公开制度或案例；
2. 原始访谈、会议演讲、论文和研究报告；
3. 权威媒体对具体组织实践的独立报道；
4. 二手评论只用于发现线索，不作为关键结论唯一来源。

禁止使用：

- 无法追溯原始出处的截图；
- 只描述产品能力、不证明真实组织使用的营销文案；
- 将单一案例外推为全行业趋势；
- 用AI生成摘要代替原文核验。

## 4. 反例要求

事实包必须主动寻找：

- 经验难以被提取或提取后质量下降的案例；
- 组织拥有知识库但无法在真实任务中调用的案例；
- 过度标准化导致判断僵化的案例；
- 专家与系统共同升级，而非零和替代的案例。
